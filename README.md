# 语盾·农信 LinguaShield Agri · 源码说明

面向**农业国际合作邮件**的中英双语风险识别与核验辅助系统。

作者：刘湘宁（福建农林大学 2026 级英语专业 1 班）　合作者：林杭（软件工程 2 班）

---

## 一、这是什么

农业国际合作往来邮件（询盘、报价、单证、结算）是 BEC（商务邮件诈骗）的高发场景。
据 FBI 与 FDA-OIC、USDA 联合公告 **AA22-340A（2022-12）**，"农业与食品供应链"
被明确点名，典型手法为：变更收款账户、伪造紧急大额订单、物流改道、冒充高管要求保密。

语盾·农信 做两件事：

1. **风险识别** —— 判断这封邮件"像不像诈骗"，给出分数、等级与可读的判定理由；
2. **核验辅助** —— 回答"这封邮件我该怎么核实"，给出第二渠道核验、域名比对、
   邮件鉴权（SPF/DKIM/DMARC）与处置建议清单。

**设计立场：本系统做"风险提示 + 核验引导"，不代替人工判断、不下结论。**

## 二、文件说明

| 文件 | 作用 |
|---|---|
| `rules.py` | 规则库：中英文话术组、分组基础分、组合规则、核验参数 |
| `engine.py` | 检测引擎：归一化、语言判定、URL 信誉、话术匹配、组合规则、**核验辅助层** |
| `gen_samples.py` | 生成基础测试集（100 条，校园/学术场景） |
| `gen_agri_samples.py` | **追加**农业国际合作样本（S105 起，30 条） |
| `samples.csv` | 134 条标注测试集（source 字段逐条注明来源） |
| `run_eval.py` | 主评测脚本，输出四项指标与混淆矩阵 |
| `run_holdout.py` | **留出样本检验**（32 条，撰写规则时未参考过）★最能说明泛化能力 |
| `ablation.py` | 三档消融实验 |
| `run_test.py` | 12 条样本快速演示（含 4 条农业场景） |
| `corpus_B_keywords.py` | 关键词表与 LL 对数似然比检验（语料库语言学方法） |
| `corpus_B_robust.py` | 多重参照稳健性检验（效应量门槛 + 阴性对照） |
| `holdout/holdout_agri.csv` | 留出样本数据 |
| `*.txt` | 上述脚本的运行输出 |

## 三、运行方式

无需安装任何第三方库，Python 3.8+ 即可：

```bash
python run_eval.py           # 主评测：四项指标与混淆矩阵
python run_holdout.py        # 留出检验（最能说明泛化能力）
python ablation.py           # 三档消融实验
python run_test.py           # 12 条演示（含农业场景）
python corpus_B_keywords.py  # 关键词表与 LL 检验
python corpus_B_robust.py    # 多重参照稳健性检验
```

### 当前实测结果

| 数据集 | 条数 | 准确率 | 精确率 | 召回率 | 误报率 |
|---|---|---|---|---|---|
| 主测试集 `samples.csv` | 134 | 100.0% | 100.0% | 100.0% | 0.0% |
| **留出样本** `holdout/` | 32 | 100.0% | 100.0% | 100.0% | 0.0% |

其中农业国际合作场景共 44 条（主测试集 30 条 + 留出 32 条中的 30 条，
中英各半，钓鱼/正常各半），**全部判对**。

### 关于"满分"的说明（重要）

`samples.csv` 与 `rules.py` 出自同一作者，在它上面取得高分是必然的，
**说明不了泛化能力**。所以本包额外提供 `holdout/holdout_agri.csv`：
一组在撰写规则时刻意**未参考过**的农业邮件。

留出检验首次运行时召回率仅 **61.1%**（18 条钓鱼漏 7 条），
暴露了三处真实缺陷（第一人称写法覆盖不全、中文侧缺"账户异常"组、
组合规则缺"改账户+保密"这一脚）。修补后达到 100%。
这一"先失败、再修正"的过程记录在本目录 `留出检验报告.txt` 与提交材料中，
比天生满分更可信。

### 消融实验（主测试集 134 条，报警阈值 ≥40 分）

| 配置 | 召回率 | 说明 |
|---|---|---|
| Tier 1 仅 URL 层 | 5.0% | 绝大多数诈骗邮件不带可疑链接 |
| Tier 2 URL + 话术 | 36.7% | 话术库是主要贡献层 |
| Tier 3 全量（含组合规则） | 100.0% | 组合规则是不可替代的一层 |

结论：**本系统的判别力来自语言层（话术 + 组合），而非技术层。**
这也是英语专业学生在此类项目中的独占价值所在。

## 四、方法说明（语料库语言学依据）

规则库不是凭感觉写的，而是用两个统计门槛筛出来的：

1. **对数似然比 LL 检验**（Gabrielatos & Marchi 2012），临界值 `CRIT = 15.13`（p < 0.001）；
2. **效应量 LogRatio ≥ 3**（约 8 倍频差），淘汰"统计显著但实际差别很小"的单词。

阴性对照（与诈骗无关的中性词）在这套门槛下全部被剔除，说明检验具备区分能力。

**本方法的重要发现**：单词级特征在真实邮件参照下普遍不稳（19 个信号词仅 4 个通过
双重门槛），因为 `account` 这类词在真实商务邮件里同样高频。诈骗的判别力不在
"用哪个词"，而在"怎么组合这些词"。这正是语盾放弃关键词过滤、改用
**话术短语 + 组合规则**的数据依据 —— 若按关键词做，在真实邮件上必然大量误报。

## 五、关于参照语料数据集（重要）

`corpus_B_robust.py` 中的 R2/R3 参照语料来自公开的 **Enron-Spam** 数据集。
因附件体积限制，本包**未包含**该数据文件（原始 CSV 约 5 MB）。

如需完整复现稳健性检验，请自行下载并放置：

1. 下载地址（GitHub 公开镜像）：
   https://raw.githubusercontent.com/muskanchugh-ds/Spam-Email-Classification/master/spam_ham_dataset.csv
2. 在本目录下新建 `corpus_raw/` 文件夹，将文件保存为：
   `corpus_raw/spam_ham_dataset.csv`
3. 重新运行 `python corpus_B_robust.py`

数据出处：
Metsis, V., Androutsopoulos, I., & Paliouras, G. (2006).
*Spam Filtering with Naive Bayes — Which Naive Bayes?* CEAS 2006.

未放置该数据时脚本仍可运行，但会退化为仅使用 R1 自建参照语料。

## 六、已知局限

- 测试集与留出集均为自建样本，结论应表述为"在该样本集上成立"，不等于真实世界表现。
- Enron 属企业邮件体裁，与农业/学术场景存在体裁差异，已在报告中说明。
- 规则库为人工整理，覆盖的是**已见过的** BEC 手法；新变种需要持续补充。
- 仅检测文本内容，不处理附件、图片型钓鱼，也不做链接实访（避免触发风险）。
- **不代替人工判断**：所有输出均为"风险提示"，最终核实责任在用户。
